# Demmy☆ — one-page portfolio

Dark, minimalist, playful personal portfolio built with React + Vite.

## Run

```bash
npm install
npm run dev
```

## Design direction

Charcoal + olive + brown + dusty pink + cream, with subtle hover effects, project modals, tiny interactive popups, a Stranger Things reference, basketball/chess personality stats, and a deliberately restrained amount of chaos.

## Before publishing

- Replace `hello@example.com` with your email.
- Add your LinkedIn and GitHub URLs.
- Replace project artwork with real screenshots when ready.
- Add your actual resume link if you want one.
